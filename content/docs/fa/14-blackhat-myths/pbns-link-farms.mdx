## مفهوم

**PBN** یا شبکهٔ بلاگ خصوصی، گروهی از سایت‌های تحت کنترل یا اجاره است که عمدتاً برای ساخت لینک رتبه‌ساز به سایت هدف استفاده می‌شود. **مزرعهٔ لینک** هم سایت یا شبکه‌ای است که حجم زیادی cross-link کم‌ارزش برای همین هدف تولید می‌کند. این رفتار زیر link spam می‌رود؛ تغییر کاربری دامنهٔ منقضی فقط برای اعتبار قبلی هم می‌تواند expired-domain abuse باشد.

یک سایت فقط چون خصوصی است، مالک مشترک دارد، روی WordPress Multisite است، از یک CDN استفاده می‌کند یا عضو portfolio ناشر است خودکار PBN نمی‌شود. خط مرزی **هدف دستکاری لینک** است. برندهای واقعی ممکن است ناوبری مشترک داشته باشند یا جایی که برای کاربر مفید است به هم ارجاع بدهند. شبکه وقتی آلوده می‌شود که property یا صفحه اساساً برای تولید اعتبار رتبه ساخته شده باشد.

این مطلب برای تشخیص، governance و پاکسازی است؛ راهنمای پنهان کردن مالکیت یا دور زدن تشخیص نمی‌دهد.

## چرا مهم است

لینک شبکه یک وابستگی ناپایدار است: ممکن است نادیده گرفته شود، حذف شود یا به manual action برسد. در acquisition هم ممکن است بدهی از footer قدیمی، ریدایرکت دامنهٔ منقضی یا قرارداد فروشنده به ارث برسد.

<CorrectExample title="درست">
یک شرکت سایت محصول، مستندات و status page دارد. هرکدام مخاطب و کار جدا دارند. ناوبری مشترک رابطه را شفاف می‌گوید و لینک contextual فقط وقتی می‌آید که مفید باشد:

```tsx
<nav aria-label="سرویس‌های شرکت">
  <a href="https://example.com/">محصول</a>
  <a href="https://docs.example.com/">مستندات</a>
  <a href="https://status.example.com/">وضعیت سرویس</a>
</nav>
```

حتی اگر موتور جست‌وجو هیچ اعتباری پاس ندهد، هر سه سایت باز هم دلیل واقعی برای وجود دارند.
</CorrectExample>

<IncorrectExample title="غلط" why="دامنه‌ها و مقاله‌ها مخاطب یا کار مستقل ندارند؛ شغلشان فرستادن exact-match link به URL هدف است و این دستکاری لینک محسوب می‌شود.">
فروشنده دامنه‌های منقضی نامرتبط می‌خرد، «review» نازک منتشر می‌کند و در همه همان انکر تجاری را به یک مشتری می‌دهد. footer سایت‌واید نودها را به هم وصل می‌کند. قرارداد تعداد لینک رتبه‌ساز را تضمین می‌کند، نه خواننده، referral یا تصمیم تحریریه.
</IncorrectExample>

## پیاده‌سازی وردپرس

**Yoast SEO**

1. canonical و sitemap تمیز، شبکه‌ای را که برای لینک ساخته شده مشروع نمی‌کند.
2. footer قالب، reusable block، bio نویسنده و پست import‌شده را برای لینک تجاری موروثی audit کن.

**Rank Math**

1. از Redirections برای فرستادن دامنهٔ منقضی نامرتبط به صفحهٔ پول‌ساز استفاده نکن.
2. موقع cleanup، redirect و دادهٔ لینک را export کن تا حذف‌ها قابل بازبینی باشند.

**AIOSEO**

1. تنظیمات Multisite برای property واقعی مناسب است؛ مدرک compliant بودن شبکهٔ لینک نیست.
2. placement پولی را با `rel="sponsored"` مشخص کن و اعتبار رتبه را تضمین نکن.

**جا خالی واقعی:** هیچ افزونه‌ای هدف تجاری یا گراف مالکیت پشت لینک را نمی‌فهمد. قرارداد، فاکتور، سابقهٔ تحریریه، تاریخچهٔ دامنه/هاست و backlink review لازم است.

## پیاده‌سازی Next.js

لینک را در component ساده و قابل بازبینی نگه دار و برای placement پولی رابطهٔ درست بده:

```tsx
type PartnerLinkProps = {
  href: string;
  label: string;
  paid: boolean;
};

export function PartnerLink({ href, label, paid }: PartnerLinkProps) {
  return (
    <a href={href} rel={paid ? "sponsored" : undefined}>
      {label}
    </a>
  );
}
```

در App Router، از لیست دامنه گراف لینک خروجی سایت‌واید نساز و با `proxy.ts` لینک متفاوت به Googlebot نشان نده. لینک آلوده را از منبع بردار؛ برای محتوای شبکه‌ای که جایگزین مرتبط ندارد `410` مناسب است.

یادداشت Pages Router: همین قانون برای `_app`، `getStaticProps` و footer تغذیه‌شده از API برقرار است. انتخاب framework، cross-link کنترل‌شده را editorial نمی‌کند.

## اشتباه‌های رایج و افسانه‌های منسوخ

- **DEPRECATED:** «Theme یکتا و IP جدا PBN را امن می‌کند.»
- **DEPRECATED:** «هر سایت یا شبکهٔ خصوصی خودکار PBN است.»
- **DEPRECATED:** «بعد از هر کمپین لینک پولی، disavow بیمهٔ روتین است.»
- دیدن تبادل سه‌طرفه به‌عنوان loophole.
- 301 همهٔ دامنه‌های منقضی موروثی به قوی‌ترین money page.
- اسم گذاشتن «digital PR» روی مزرعه بدون ناشر، مخاطب و تصمیم تحریریه.

## نکته‌های سطح بالا / پروداکشن

در due diligence فروشنده بپرس دقیقاً چه می‌خری. برای ایده، پژوهش، تولید، outreach یا sponsorship واقعی پول بده؛ نه لینک تضمینی برای رتبه. URL زنده، نوع رابطه، فاکتور و تماس تحریریه را نگه دار.

اگر طرحی به ارث رسیده: placement جدید را ببند، لینک و ریدایرکت را inventory کن، چیزی که کنترل می‌کنی بردار، برای شخص ثالث درخواست حذف بده و برای لینک مصنوعی حل‌نشده disavow را بررسی کن. اگر manual action هست، بعد از پاکسازی جدی reconsideration مستند بفرست.

نود بازنشسته را به سایت هدف 301 نکن؛ ممکن است همان مشکل را متمرکز کند. راهنمای «کم کردن footprint» منتشر نکن. تست ماندگار این است که property و لینک بدون اعتبار رتبه هم برای آدم‌ها فایده داشته باشند.

## چطور مطمئن شوی

| بررسی | قبول | رد |
| --- | --- | --- |
| دلیل وجود property | مخاطب و فایدهٔ مستقل | عمدتاً برای لینک ساخته شده |
