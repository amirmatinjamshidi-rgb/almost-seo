## مفهوم

**عمق** یعنی سند شغلی را که SERP گذاشته تمام می‌کند (نیت ماژول ۰۱). کوئری ماشین‌حساب ماشین‌حساب کار می‌خواهد. کوئری سیاست قانون فعلی دقیق می‌خواهد. کوئری محصول مشخصات و حقیقت موجودی می‌خواهد. تعداد کلمه محصول جانبی است، هدف نیست.

**E-E-A-T آن‌پیج** (تجربه، تخصص، اعتبار، اعتماد — مفهوم ریتِر، آف‌پیج ماژول ۰۴) اینجا *دیدنی* است: بایلاین آدم واقعی، تاریخ، روش، منبع، «اندازه گرفتیم / منتشر کردیم،» تماس، HTTPS. JSON-LD جایگزین بایو نیست. « medically reviewed by» جعلی از هیچ بدتر است (ماژول ۰۴ / ۰۹ YMYL).

محتوای نازک و **doorway** (نزدیک-تکراری مقیاس‌شده برای کوئری) سیاست اسپم است. تازه کردن مهر تاریخ بدون جوهر، عمق نیست.

## چرا مهم است

صفحهٔ کم‌عمق bounce می‌کند و ریتِر را می‌بازد. صفحهٔ بادکرده که نتیجهٔ اول SERP را با صفت اضافه تکرار می‌کند هم می‌بازد. عمق *پوشش شغل* است، نه طول.

## پیاده‌سازی وردپرس

**Yoast SEO**

1. نوار readability / تعداد کلمهٔ یواست گوگل نیست. «too short» را روی صفحهٔ تعریف ۴۰۰ کلمه‌ای درست نادیده بگیر.
2. آرشیو نویسنده: بایو واقعی یا `noindex` نویسندهٔ خالی.

**Rank Math**

1. نمرهٔ محتوا در Rank Math برای heading/کلمهٔ بیشتر نق می‌زند. برای سبز پد نکن.
2. Schema Person: فقط کاربر واقعی.

**AIOSEO**

1. TruSEO در AIOSEO همان تله.
2. ماژول «E-E-A-T» که فهرست جایزهٔ خالی می‌گذارد: پر کن یا خاموش کن.

**جا خالی واقعی:** هر چهار پلاگین توکن نمره می‌دهند. هیچ‌کدام متخصص دامنه را از spinner تشخیص نمی‌دهند. readability در SEOPress همان کلاس است.

## پیاده‌سازی کد

```tsx
export default async function Page() {
  const doc = await getDoc("robots-txt");
  return (
    <article>
      <h1>{doc.title}</h1>
      <p>
        Last reviewed {doc.lastReviewed} · {doc.authors.join(", ")}
      </p>
      {doc.body}
    </article>
  );
}
```

App Router: بدنه از MDX/CMS روی سرور. Pages Router: `getStaticProps`. تنها پاراگراف یکتا را پشت «ادامه مطلب» که در HTML نیست قایم نکن.

اگر آدم ادعا می‌کنی صفحهٔ نویسنده مسیر واقعی باشد (ماژول ۰۴).

## اشتباه‌های رایج و افسانه‌های منسوخ

- **DEPRECATED:** حداقل ۳۰۰ / ۵۰۰ / ۲۰۰۰ کلمه برای رتبه.
- **DEPRECATED:** «Skyscraper» به‌عنوان کپی نتیجهٔ اول به‌علاوهٔ ۵۰۰ کلمه.
- تازه‌سازی فقط-تاریخ (`Updated 2026`) بدون diff.
- صفحهٔ شهر doorway به‌عنوان «عمق در مقیاس.»
- E-E-A-T به‌عنوان چک‌باکس پلاگین.

## نکته‌های سطح بالا / پروداکشن

بریف باید **سؤالی که URL باید جواب دهد** را لیست کند، از SERP + GSC + متخصص، نه تعداد کلمه. برای YMYL، بازبین نام‌دار و تاریخ عملیاتی است، تزئینی نه.

URL نازک را prune یا ادغام کن (ماژول ۰۶) نه پد.

`last_reviewed` در frontmatter همین دانشنامه مکانیزم صداقت است — وقتی ویرایش می‌کنی واقعی نگه دار.
