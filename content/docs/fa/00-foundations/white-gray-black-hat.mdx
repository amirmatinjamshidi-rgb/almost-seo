## مفهوم

**White / gray / black hat** طبقه‌بندی *اهل فن* است. مستند گوگل با **spam policies** و **manual actions** حرف می‌زند، نه رنگ کلاه.

- **White hat.** چیزی که جلوی ریویوور با رو می‌گویی: محتوای یکتای crawlپذیر، عنوان صادق، لینک به‌دست‌آمده، structured data درست، NAP واقعی، کار پرفورمنس دسترس‌پذیر. با Search Central و spam policy می‌خواند.
- **Black hat.** نقض سیاست اسپم: cloaking، متن/لینک مخفی، doorway، لینک هک، link scheme (PBN، لینک پولی بدون `rel="sponsored"` / `nofollow` وقتی لازم است)، scaled content abuse، expired domain abuse، site reputation abuse، keyword stuffing برای پنهان‌کاری.
- **Gray hat.** اصطلاح بازار برای ریسک: نه صریح مجاز، نه همیشه امروز تنبیه. مهمان‌نویس تهاجمی، خرید دامنه‌ی منقضی برای ریدایرکت (الان زیر expired-domain abuse خطرش نوشته شده)، اسکیل اسکرپ-بازنویسی. خاکستری منطقه‌ی امن نیست؛ ریسک قیمت‌نخورده است.

اگر حقوقی یا مشتری پرسید «مجاز است؟» از **متن فعلی spam policies** جواب بده، نه از پست رنگ کلاه.

## چرا مهم است

باقیمانده‌ی کلاه سیاه (شبکه‌ی لینک، صفحه‌ی cloaked، قالب doorway) ممکن است دامنه را سال‌ها سقف بگذارد. کار سفید جمع می‌شود. برد خاکستری اغلب همان هفته‌ای که کلاسیفایر بهتر می‌شود، در GSC پرتگاه می‌شود. برند را روی تأخیر اعمال شرط می‌بندی.

<CorrectExample title="درست">
لینکی که در ریویو compliance دفاع می‌شود:

```html
<article>
  <p>
    طبق اندازه‌گیری میدانی Example Labs،
    <a href="https://www.yoursite.com/fa/research/crawl-log-study">
      مطالعه‌ی لاگ خزش
    </a>
    کامل منتشر شده است.
  </p>
</article>
```

داده دادی، دبیر انتخاب کرد ارجاع بدهد، لینک داخل بدنه است، مقصد URL پژوهش است. اگر پرسیدند، ترد ایمیل و فایل مطالعه را داری.
</CorrectExample>

<IncorrectExample title="غلط" why="Link scheme و expired-domain abuse سیاست اسپم‌اند؛ این «منطقه‌ی خاکستری» نیست که بعداً با nofollow سفیدش کنی.">
```html
<!-- چهل دامنه‌ی پیر 301 به /money-page، لینک فوتر سراسری -->

```

به‌علاوه PBN: قالب وردپرس یکسان، مقاله‌ی بازیافتی، ایندکس خصوصی IP فقط برای رتبه‌ی سایت پول.
</IncorrectExample>

## پیاده‌سازی وردپرس

**Yoast SEO**

1. Yoast PBN را تشخیص نمی‌دهد. robots و canonical صادق را می‌تواند بدهد — استفاده کن. مقاله‌ی واقعی را `noindex` نکن و نسخه‌ی کلمه‌پرکن را فقط به Googlebot نشان بده؛ اسمش cloaking است.
2. صفحه‌ی تشکر را noindex کردن عادی است. لندینگ تجاری که می‌خواهی رتبه بگیرد را noindex نکن.

**Rank Math**

1. Redirections: ۳۰۱ دامنه‌ای که *همان سایت* بوده (مهاجرت) درست است. ده‌ها هاست نامرتبط منقضی را به یک URL پول قیف نکن.
2. ۴۰۴ مانیتور برای بهداشت است، نه دوشیدن لینک سایت هک‌شده.

**AIOSEO**

1. Redirect Manager: همان قانون. مهاجرت بله؛ شبکه‌ی link scheme خیر.
2. ماژول Local، NAP جعلی یا doorway شهری را قانونی نمی‌کند.

**SEOPress:** ریدایرکت و robots قوی‌اند. قابلیت ≠ مجوز. خط سیاست یکی است.

**جا خالی:** هر چهار پلاگین ۳۰۱ از دامنه‌ی منقضی را با خوشحالی می‌زنند. هیچ‌کدام هشدار spam-policy نمی‌دهند. این گپ اخلاق محصول است، نه چک‌باکس گم‌شده.

## پیاده‌سازی کد

Cloaking با middleware کلاسیک‌ترین تله‌ی Next است:

```ts
import { NextResponse } from "next/server";
import type { NextRequest } from "next/server";

export function proxy(request: NextRequest) {
  // مجاز: مسیر زبان، گیت auth برای اپ خصوصی، geo برای محدودیت قانونی
  // غیرمجاز: HTML متفاوت برای Googlebot در مقابل Chrome
  return NextResponse.next();
}
```

همان مقاله‌ی HTML را به Googlebot و کاربر بده. اگر geo می‌بندی، صفحه‌ی توضیح crawlپذیر ثابت برگردان، نه نسخه‌ی کلمه‌پرکن.

در Pages Router، `getServerSideProps` که با user-agent فقط برای گوگل کلمه‌ی اضافه می‌دهد cloaking است. در App Router چک `headers()` که تایتل را برای `Googlebot` عوض کند همان تخلف است.

افیلیت صادق:

```html
<a href="https://vendor.example/offer" rel="sponsored">پیشنهاد فروشنده</a>
```

## اشتباه‌های رایج و افسانه‌های منسوخ

- **DEPRECATED:** «دیگر گوگل PBN را تنبیه نمی‌کند.» سیستم لینک‌اسپم هست؛ اعمال نابرابر است. نابرابر ≠ مجاز.
- **DEPRECATED:** «`nofollow` روی لینک پولی سراسری سفیدش می‌کند.» لینک پولی که قرار است اعتبار بدهد باید `sponsored` باشد (یا nofollow اگر sponsored نمی‌توانی). پنهان کردن پولی بودن مسئله است.
- **DEPRECATED:** لیست کلمه با `display:none` به‌عنوان تاکتیک رتبه.
- «خاکستری کار آژانس است پس خوب است.» آژانس هم برای مشتری manual action می‌گیرد.
- قاطی کردن **penalized** (اکشن دستی) با **filtered** (افت الگوریتمی). هر دو می‌توانند از باقیمانده‌ی کلاه سیاه بیایند.

## نکته‌های سطح بالا / پروداکشن

سازمان‌ها بیشتر روی خاکستری می‌بازند تا cloaking کارتون: شبکه‌ی پست مهمان، لینک اینسرت ۲۰۱۴، میکروسایت روی دامنه‌ی منقضی که حقوقی ندیده. موجودی لینک و مسیر پاکسازی/disavow داشته باش. disavow مجوز ساخت زباله نیست؛ آخرین تیر بعد از تمیزکاری است.

خبر و مارکت‌پلیس: اسپم کاربر (لینک کامنت، فروشگاه جعلی) می‌تواند شبیه link scheme خودت دیده شود. модеراسیون کنترل SEO است.

دامنه که به ارث بردی: manual actions، sanity از `site:`، پروفایل لینک تاریخی، Wayback صفحه‌ی اول، نمونه‌ی لاگ Googlebot. بدون این intake داخل هاست قبلاً سوخته محتوا نریز.
