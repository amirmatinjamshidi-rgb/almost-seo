## مفهوم

SERP دیگر «ده تا لینک آبی» نیست. برای هر کوئری گوگل یک **چیدمان از نوع‌نتیجه** می‌چیند. نتیجه‌ی ارگانیک هنوز مهم است؛ صفحه‌اش را با تبلیغ، local pack، تصویر/ویدیو، خبر، بحث‌ها، featured snippet، People Also Ask، knowledge panel، شاپینگ و — هر جا رول‌اوت شده — **AI Overviews** / AI Mode شریک می‌شود.

هر بلوک شرط ورود خودش را دارد:

- **نتیجه‌ی ارگانیک.** لینک عنوان، URL/breadcrumb، اسنیپت.
- **Featured snippet.** یک قطعه یا لیست از صفحه؛ گاهی بالای ارگانیک کلاسیک.
- **People Also Ask.** سؤال‌های مرتبط؛ منبع‌ها می‌چرخند.
- **Local pack.** برای نیت محلی؛ سیگنال GBP و لوکال غالب است.
- **Knowledge panel.** گراف موجودیت. با «پلاگین پنل دانش» روشن نمی‌شود.
- **Sitelinks.** لینک‌های اضافه زیر دامنه‌ای که ساختارش برای گوگل واضح است. سوییچ ندارد.
- **Ads / Shopping.** پولی. کار SEO این اسلات را نمی‌خرد.
- **AI Overview.** خلاصه‌ی تولیدی با لینک پشتیبان. citation یعنی منبع کمکی، نه «رتبه ۱ کلاسیک».

نیت کوئری ترکیب را عوض می‌کند. «لوله کش نزدیک من» محلی است. «crawl budget چیست» اطلاعاتی و اسنیپت‌خوار است. «خرید دستگاه اسپرسو دو گروپ» تجاری/محصول است.

## چرا مهم است

اگر فقط برای رتبه ۱ کلاسیک بهینه کنی، چیدمانی که واقعاً بالا می‌آید را ندیده‌ای. ممکن است داخل snippet یا citation هوش مصنوعی باشی و کلیک بگیری — یا کلیک را به Overview ببازی. SERP امروز را اندازه بگیر، نه اسکرین شات ۲۰۱۴ را.

## پیاده‌سازی وردپرس

**Yoast SEO**

1. گراف schema (Organization، WebSite) برای *واجد شرایط بودن* پنل دانش است، نه رزرو پنل.
2. Breadcrumbs اگر با معماری واقعی یکی باشد، مسیر اسنیپت را تمیزتر می‌کند.
3. سوییچ «position zero» در Yoast وجود ندارد. HTML قابل استخراج بنویس.

**Rank Math**

1. Schema را Article/BlogPosting بگذار برای مقاله؛ FAQ فقط وقتی همان سؤال‌ها روی صفحه دیده می‌شوند.
2. پیش‌نمایش rich snippet در پلاگین، رزرو SERP نیست.

**AIOSEO**

1. عنوان‌ها سند را توصیف کنند، نه «خانه - سایت - سایت».
2. FAQ مخفی با schema و بدون FAQ روی صفحه، می‌رود سمت spam policy.

**جا خالی:** Rank Math و AIOSEO نوع schema بیشتری در ادیتور نشان می‌دهند. نوع بیشتر به‌تنهایی ویژگی SERP بیشتر نمی‌سازد. SEOPress هم قدرتمند است و همان‌قدر برای over-markup وسوسه‌انگیز.

## پیاده‌سازی کد

Sitelinks را در Next روشن نمی‌کنی. فقط ساختار را واضح می‌کنی:

```tsx
import type { Metadata } from "next";

export const metadata: Metadata = {
  title: "crawl budget چیست و کی واقعاً مسئله می‌شود",
  description:
    "ترکیب ظرفیت خزیدن گوگل‌بات و تقاضای آن. تشخیص با لاگ و Search Console.",
};

export default function Page() {
  return (
    <main>
      <h1>crawl budget چیست؟</h1>
      <p>{/* جواب مستقیم ۴۰–۶۰ کلمه‌ای */}</p>
      <nav aria-label="Breadcrumb">
        <ol>
          <li><a href="/fa/docs">مستندات</a></li>
          <li>آناتومی SERP</li>
        </ol>
      </nav>
    </main>
  );
}
```

FAQPage JSON-LD فقط کنار پرسش‌وپاسخ دیده. Pages Router: همان قانون HTML.

## اشتباه‌های رایج و افسانه‌های منسوخ

- **DEPRECATED:** «meta keywords اسنیپت را پر می‌کند.» سال‌هاست نادیده گرفته می‌شود.
- **DEPRECATED:** «Sitelinks را از Yoast روشن کردیم.» تولیدی است، سوییچ پلاگین نیست.
- **DEPRECATED:** «featured snippet همیشه CTR بهتر است.» گاهی جواب را همان‌جا می‌دهد و کلیک می‌خوابد. در GSC اندازه بگیر.
- FAQ schema برای سؤالی که روی صفحه نیست، برای شکار PAA.
- citation هوش مصنوعی را مثل رتبه ثابت حساب کردن. چیدمان با لوکیل و آزمایش عوض می‌شود.

## نکته‌های سطح بالا / پروداکشن

ویژگی SERP به کوئری و کشور حساس است. ترکری که فقط «رتبه ۳» ذخیره می‌کند، روی کوئری برند و لوکال و AI دروغ می‌گوید. در اسکیل، occupancy بساز: organic، snippet، PAA، local، shopping، citation.

SERP برند (کوئری = نام خودت) شغل جداست: بهداشت knowledge panel، sitelinks، اعتبار. قالبش با پست head-term یکی نیست.

تایتل را فقط با رتبه A/B نکن؛ ببین snippet از دست رفت یا citation آمد.

## چطور مطمئن شوی

| ابزار | قبول | رد |
| --- | --- | --- |
| SERP دستی (لوکیل هدف، لاگ‌اوت) | چیدمان با نیتی که نوشتی می‌خواند | مقاله نوشتی؛ گوگل فقط local pack نشان می‌دهد |
| GSC Search results | برای خانواده‌ی کوئری impression/click هست | کوئری فقط برند است و تو خیال head-term داری |
| Rich Results Test | schema با محتوای دیده یکی است | FAQ schema بدون FAQ |
| Ahrefs یا مشابه | occupancy ویژگی در زمان | فقط position روی کوئری اسنیپت‌دار |
| URL Inspection | canonical همان URL بهینه‌شده است | اسنیپت از duplicate ناخواسته می‌آید |
