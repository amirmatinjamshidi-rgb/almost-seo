## مفهوم

سرچ گوگل یک **پشته از ranking systems** است، نه یک فرمول مخفی. نقشه‌ی عمومی‌اش همان صفحه‌ی Search Central به اسم راهنمای ranking systems است. تا وقتی عوضش نکرده‌اند، همان را مبنا بگیر.

سه لایه که واقعاً باهاش کار می‌کنی:

1. **بازیابی و رتبه‌ی سند.** سیستم‌های core، ربط و کیفیت سند ایندکس‌شده را برای کوئری می‌سنجند. سیگنال page experience مثل Core Web Vitals می‌تواند وارد شود؛ جایگزین ربط نیست.
2. **سیستم اسپم و سوءاستفاده.** لینک اسپم، cloaking، expired domain abuse، scaled content abuse، site reputation abuse. «Helpful Content» دیگر پیچ جداگانه‌ی ماهانه نیست؛ گوگل آن را از مارس ۲۰۲۴ داخل core برد. core update هنوز می‌آید؛ با عوض کردن یک تگ برنمی‌گردد.
3. **ارزیاب انسانی ≠ نمره‌ی رتبه.** در Quality Rater Guidelines مفهوم **EEAT** هست. ارزیاب موقعیت تو را ست نمی‌کند. برچسب‌هایشان برای آموزش و ارزیابی سیستم است. متاتگ EEAT نداریم.

سیستم‌های نام‌دار دیگر وقتی موضوع‌شان است وارد می‌شوند: نقد و بررسی، لوکال، شاپینگ، طبقه‌بند اسپم.

وقتی کسی می‌گوید «الگوریتم زد»، بپرس: پنجره‌ی core update، اکشن اسپم، حذف فنی از ایندکس، یا عوض شدن چیدمان SERP. چهار تیکت جدا.

## چرا مهم است

تیم‌ها فصل‌ها چک‌لیست عصر Panda/Penguin را می‌دوند. مدل ۲۰۲۶ این است: سند بهترین نتیجه برای کوئری باشد، داخل spam policy بمانی، URL در ایندکس بماند. فولکلور آپدیت اسم‌دار بدون تشخیص GSC یا لاگ، استراتژی نیست.

## پیاده‌سازی وردپرس

**Yoast SEO**

1. Organization/Person واقعی بگذار. structured data است، نمره‌ی EEAT نیست.
2. اگر نویسنده‌ها لندینگ واقعی نیستند، آرشیو نویسنده را noindex کن.
3. Cornerstone در Yoast فقط راهنمای لینک داخلی است، سیستم رتبه‌بندی گوگل نیست.

**Rank Math**

1. چراغ Content AI هیوریستیک پلاگین است، دستورالعمل ارزیاب گوگل نیست.
2. SEO Analyzer یک طبقه‌بندی اسپم سایت‌واید را برنمی‌گرداند. محتوا و لینک را درست کن.

**AIOSEO**

1. TruSEO چک‌لیست آن‌پیج است. «الگوریتم» نیست.
2. اتصال GSC را بگذار؛ تشخیص در GSC است نه ویجت نمره.

**جا خالی:** Rank Math و AIOSEO نمره‌ی ادیتوری بیشتری از Yoast نشان می‌دهند؛ همبستگی‌شان با سیستم رتبه‌بندی ضعیف است. SEOPress خلوت‌تر است و برای ادیتور اغلب سالم‌تر.

## پیاده‌سازی کد

APIای به اسم `rankingSystem: 'core'` نیست. کیفیت را در HTML نشان بده:

```tsx
import type { Metadata } from "next";

export const metadata: Metadata = {
  title: "تورم پیچ‌خوردگی مچ پا معمولاً چقدر می‌ماند",
  authors: [{ name: "دکتر سارا ن.", url: "https://example.com/fa/authors/sara-n" }],
  robots: { index: true, follow: true },
};

export default function Page() {
  return (
    <article>
      <h1>تورم پیچ‌خوردگی مچ پا معمولاً چقدر طول می‌کشد؟</h1>
      <p>
        <a href="/fa/authors/sara-n">دکتر سارا ن.</a>
        <time dateTime="2026-06-12">بازبینی ۱۲ ژوئن ۲۰۲۶</time>
      </p>
    </article>
  );
}
```

JSON-LD `Person` / `Article` باید با بای‌لاین دیده یکی باشد. Pages Router: بدون UI نویسنده، schema نویسنده تزریق نکن.

## اشتباه‌های رایج و افسانه‌های منسوخ

- **DEPRECATED:** درصد keyword density به عنوان سیستم رتبه. گوگل سال‌هاست می‌گوید هدف تراکم ندارد. stuffing هنوز ضرر دارد.
- **DEPRECATED:** meta keywords به‌عنوان سیگنال رتبه.
- **DEPRECATED:** Domain Authority موز = سیستم گوگل. متریک شخص ثالث است.
- **DEPRECATED:** Panda/Penguin را دکمه‌ی ماهانه‌ی زنده دانستن. ایده‌شان سال‌هاست جذب شده.
- قاطی کردن **manual action** با core update. اکشن دستی گزارش و مسیر تجدیدنظر دارد.
- خرید «بک‌لینک EEAT» به‌عنوان محصول.

## نکته‌های سطح بالا / پروداکشن

در سایت بزرگ core update بخش‌ها را یکدست تکان نمی‌دهد: زیرشاخه‌ی نازک می‌افتد، هاب مستندات می‌ماند. GSC را بر اساس دایرکتوری و قالب و نیت ببر، نه فقط میانگین دامنه.

اسپم در اسکیل روی **الگو** شلیک می‌کند: لیستینگ جنریت‌شده، دامنه‌ی منقضی، site reputation abuse روی هاست معتبر. برند باید سیاست داشته باشد چه کسی روی دامنه‌ی اصلی منتشر می‌کند.

Page experience بیشتر تای‌بریکر است تا اهرم اول. بازنویسی ربط را برای ۲ میلی‌ثانیه INP معطل نکن اگر سند به کوئری جواب نمی‌دهد.

زمان‌حساس: گوگل سیستم را عوض نام/ادغام می‌کند. با هر آپدیت اسم‌دار صفحه‌ی ranking systems را دوباره بخوان. این متن راهنمای عمومی تا ۲۰۲۶-۰۹ است.
