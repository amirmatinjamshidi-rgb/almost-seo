## مفهوم

فایل **disavow** به گوگل می‌گوید: «اگر می‌خواستی این لینک‌ها را حساب کنی، لطفاً نکن.» در Search Console برای **propertyای که verify کردی** آپلود می‌شود. robots.txt نیست، `nofollow` روی صفحهٔ دیگران نیست، و راه مخفی کردن اسپم **روی هاست خودت** هم نیست.

راهنمای خود گوگل سال‌هاست یکی است: **بیشتر سایت‌ها به فایل disavow نیاز ندارند.** سیستم از قبل آشغال زیاد را نادیده می‌گیرد. وقتی دست می‌بری که:

- **اقدام دستی** برای لینک غیرطبیعی داری، یا حملهٔ اسپم unpaid واضحی که نمی‌توانی حذفش کنی، **و**
- لینک باقی‌مانده مال هاستی است که کنترل **نمی‌کنی**.

سینتکس (فرمت مستند گوگل): یک URL یا `domain:` per خط، کامنت `#` مجاز. آپلود کن، منتظر بمان؛ SLA نیست.

هرگز URL **خودت** را disavow نکن تا «ایندکس تمیز شود.» آن `noindex` / `404` / `410` / ریدایرکت است (ماژول ۰۳). هرگز لینکی را که **خریدی** disavow نکن به‌جای qualify از این به بعد به‌علاوهٔ پاکسازی.

## چرا مهم است

disavow شلخته می‌تواند از گوگل بخواهد همان چند ارجاع editorial باقی‌مانده را نادیده بگیرد (`domain:` بیش‌ازحد گسترده). disavow جاافتاده بعد از پاکسازی طرح لینک مستند می‌تواند اقدام دستی را باز بگذارد. هر دو خطای عملیاتی‌اند، نه ترفند رتبه.

## پیاده‌سازی وردپرس

**Yoast SEO**

1. Yoast آپلودر disavow ندارد. از GSC استفاده کن.
2. بعد از طغیان هک/پلاگین اسپم **روی هاست تو**، آن پست‌ها را حذف/410 کن (ماژول ۰۳). `https://yoursite.com/spam-page` را disavow نکن.

**Rank Math**

1. مانیتور 404 و «instant indexing» Rank Math بی‌ربط‌اند.
2. اگر Rank Math «بک‌لینک» از API پارتنر لیست کرد، از روی آن لیست auto-disavow نکن.

**AIOSEO**

1. همان: در پلاگین API جی‌اس‌سی disavow نیست که جایگزین بازبینی آدم شود.
2. ریدایرکت URL اسپم ورودی روی *سایت تو* به `/` جایگزین disavow هاست *آن‌ها* نیست — و 301-به-خانه هنوز پاکسازی بد است (ماژول ۰۳).

**جا خالی واقعی:** هیچ‌کدام از Yoast / Rank Math / AIOSEO / SEOPress فایل disavow را submit نمی‌کنند. پلاگین «نمرهٔ toxic» شخص ثالث با خوشحالی فایل ۱۰٬۰۰۰ خطی می‌سازد. همان جا خالی است: اتوماسیون بدون قضاوت.

## پیاده‌سازی کد

disavow را داخل Next.js نفرست. فایل را در git **بیرون از web root عمومی** نگه دار (دارایی رتبه نیست؛ نشتش بحران نیست، ولی `public/disavow.txt` به کسی کمک نمی‌کند):

```ts
// scripts/validate-disavow.ts — CI lint, not a route
const LINE = /^(#.*|domain:[a-z0-9.-]+|https?:\/\/\S+)$/i;

export function assertDisavow(text: string) {
  for (const raw of text.split("\n")) {
    const line = raw.trim();
    if (!line) continue;
    if (!LINE.test(line)) throw new Error(`Bad disavow line: ${line}`);
  }
}
```

App Router / Pages Router: مسیر `/disavow` نباشد. اگر باید داخلی مستند کنی، آن داک را `noindex` کن.

هرگز Route Handler ننویس که API «لینک toxic» بگیرد و به GSC پست کند. API عمومی پشتیبانی‌شده برای آن حلقه نیست.

## اشتباه‌های رایج و افسانه‌های منسوخ

- **DEPRECATED:** Disavow به‌عنوان بهداشت ماهانهٔ روتین برای هر سایت.
- **DEPRECATED:** Disavow URL هک‌شدهٔ خودت.
- **DEPRECATED:** آستانهٔ «نمرهٔ toxic» به‌عنوان فهرست گوگل.
- disavow دامنه چون رقیب است (هنوز می‌توانند به تو ارجاع بدهند؛ حمله نیست).
- آپلود مجدد فایل خالی و فرض اینکه disavow قبلی آنی محو شد — جایگزینی جایگزین می‌کند؛ در UI جی‌اس‌سی تأیید کن.
- استفاده از disavow به‌جای `rel="sponsored"` روی لینکی که هنوز می‌خری.

## نکته‌های سطح بالا / پروداکشن

فرآیند: هاست ارجاع‌دهنده را از GSC export کن (نه فقط کراولر شخص ثالث) ← طبقه‌بندی **نگه دار / درخواست حذف / disavow** ← ایمیل حذف جایی که ادیتور واقعی هست ← باقی ماندهٔ طرح را disavow کن ← **بعد** اگر اقدام دستی هست درخواست بازبینی بده.

هراس negative SEO («رقیب یک میلیون لینک اشاره کرد») معمولاً اغراق است؛ سیستم آشغال واضح را تخفیف می‌دهد. وقتی اقدام دستی هست یا شبکهٔ پولی در *تاریخ تو* واضح است عمل کن.

diff فایل disavow را در git با شناسهٔ تیکت نگه دار. توِ آینده یادت نمی‌آید چرا `domain:foo` آنجاست.

## چطور مطمئن شوی

| ابزار | قبول | رد |
| --- | --- | --- |
| ابزار disavow جی‌اس‌سی | فایل قبول شد؛ property با هاست می‌خواند | روی property `www` برای مشکل فقط-apex (یا برعکس) |
| نمونهٔ خط | هاستی که کنترل نمی‌کنی؛ باقی‌ماندهٔ طرح | دامنهٔ خودت؛ نیویورک‌تایمز «به‌خاطر DA» |
| اقدام دستی | بازبینی بعد از پاکسازی + disavow | بازبینی وقتی هنوز پست می‌خری |
| URL اسپم خودت | 410/404/ریدایرکت | داخل disavow لیست شده |
