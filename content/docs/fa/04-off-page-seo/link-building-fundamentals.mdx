## مفهوم

هایپرلینک یک ارجاع است: هاست A به خزنده و کاربر می‌گوید URL B ارزش دیدن دارد. گوگل سال‌هاست لینک را شبیه رأی حساب می‌کند. هیچ‌وقت PageRank عمومی برای URL تو منتشر نکرده و سال‌هاست لینک آسان‌بازی را ضعیف کرده.

مدل ذهنی مفید:

- **لینک editorial** — آدمی در متن بدنه به‌خاطر خواننده‌اش به تو ارجاع داده.
- **لینک qualified** — پولی، کاربرساخته، یا غیرقابل‌اعتماد با `rel="sponsored"`، `nofollow` یا `ugc` (موضوع بعد).
- **لینک سایت‌واید / قالب** — فوتر، blogroll، بایو نویسنده روی بیست سایتی که خودت کنترل می‌کنی. ارزان ساخته می‌شود؛ سیستم راحت تخفیف می‌دهد یا طرح حساب می‌کند.
- **لینک داخلی** آف‌پیج نیست. معماری است (ماژول ۰۳). در گزارش قاطی‌شان نکن.

**سیاست اسپم** گوگل (link scheme، سوءاستفاده از دامنهٔ منقضی، site reputation abuse، محتوای مقیاس‌شده برای جاگذاری لینک) همان خط است. بلاگ‌هایی که هنوز «فوترپرینت DA ۵۰» می‌فروشند Search Central نیستند.

نمی‌توانی گوگل را مجبور کنی لینک را «حساب کند.» می‌توانی لینکی بسازی که بازبین صادقانه بخواند، مقصد را crawlپذیر نگه داری (`200`، ایندکس‌پذیر، محتوای واقعی)، و آشغال نخری.

## چرا مهم است

کار آف‌پیج کند و گران است. یک ماه پست مارکت‌پلیس در نمودار «بک‌لینک» شخص ثالث شبیه رشد است و هنوز می‌تواند اقدام دستی آینده باشد. چند ارجاع از نشریهٔ واقعی روی URLی که واقعاً می‌خواهی رتبه بگیرد، اغلب از هزاران دایرکتوری بیشتر دوام می‌آورد.

## پیاده‌سازی وردپرس

**Yoast SEO**

1. Yoast لینک نمی‌خرد. canonical و robots را چاپ می‌کند تا URLی که *می‌خواهی* ارجاع شود همان باشد که Googlebot می‌گیرد.
2. Yoast ← Search Appearance: URL پول‌ساز ایندکس‌پذیر بماند. صفحهٔ تحقیق `noindex` مقصد لینک معقول نیست.
3. پیشنهاد «internal linking» در Premium آن‌پیج است. به‌عنوان بک‌لینک گزارش نکن.

**Rank Math**

1. «نمرهٔ SEO» و شمارندهٔ لینک داخل ادیتور، پروفایل بک‌لینک نیست.
2. Instant Indexing بعد از hit روابط‌عمومی لینک نمی‌سازد. فقط URL موجود را ping می‌کند.
3. ریدایرکت Rank Math را برای 301 کردن بیست دامنهٔ کهنه روی یک URL تجاری استفاده نکن (expired-domain abuse — موضوع طرح لینک).

**AIOSEO**

1. همان: بهداشت پلاگین ≠ برنامهٔ آف‌پیج.
2. مدیر ریدایرکت AIOSEO: مهاجرت بله؛ قیف دامنهٔ اجاره‌ای نه.

**جا خالی واقعی:** هیچ‌کدام از Yoast / Rank Math / AIOSEO / SEOPress لینک ورودی نمی‌خرند، مذاکره نمی‌کنند، qualify نمی‌کنند. SEOPress ماژول مخفی «link juice» ندارد. اگر داشبورد پلاگین «backlinks» نشان داد، تخمین API شخص ثالث است، نه GSC.

## پیاده‌سازی کد

آف‌پیج داخل `app/` زندگی نمی‌کند. کار اپ این است که URL ارجاع‌شده سند واقعی باشد:

```tsx
import type { Metadata } from "next";

export const metadata: Metadata = {
  title: "Crawl-log study (2026)",
  robots: { index: true, follow: true },
  alternates: {
    canonical: "https://www.example.com/research/crawl-log-study",
  },
};

export default async function StudyPage() {
  const study = await getStudy("crawl-log-study");
  return (
    <article>
      <h1>{study.title}</h1>
      <p>Published {study.date}</p>
      {study.body}
    </article>
  );
}
```

App Router: صفحات تحقیق و پول‌ساز به‌صورت Server Component با canonical پایدار. Pages Router: `getStaticProps` / `getServerSideProps` — همان قانون. پوستهٔ خالی CSR مقصد ارجاع شکسته‌است (ماژول ۰۳، رندر جاوااسکریپت).

`/go/partner-12` نساز مگر یک hop `301`/`302` عمدی است. زنجیرهٔ hop مخفی شبیه junk نزدیک cloaking است.

## اشتباه‌های رایج و افسانه‌های منسوخ

- **DEPRECATED:** PageRank تولبار به‌عنوان چیزی که هفتگی بهینه می‌کنی.
- **DEPRECATED:** «لینک بیشتر همیشه می‌برد» بدون توجه به منبع.
- **DEPRECATED:** انکر exact-match به‌عنوان cheat رتبه که می‌شود مقیاس کرد.
- شمردن لینک `nofollow` / `sponsored` در دک KPI مثل ارجاع editorial.
- زدن همهٔ لینک جدید به هوم‌پیج چون «PageRank هوم‌پیج.»
- حساب کردن Moz DA / Ahrefs DR به‌عنوان نمرهٔ گوگل.

## نکته‌های سطح بالا / پروداکشن

قبل از outreach **دارایی قابل لینک** تعریف کن: داده، ابزار، داک، عکس اصلی، صفحهٔ سیاستی که مردم از قبل ارجاع می‌دهند. بعد URLی را بردار که باید ارجاع شود (اغلب مطالعه یا hub، نه `/buy`).

در **GSC** (گزارش لینک، سایت‌های لینک‌دهنده) و referral آنالیتیکس اندازه بگیر — نه فقط ایندکس کراولر وب باز. آن ایندکس‌ها هم چیز زیاد جا می‌گذارند هم آشغال زیاد دارند.

اگر کسب‌وکار «۵۰ لینک این ماه» می‌خواهد، بریف را عوض کن به «N جاگذاری روی نشریه‌ای که خریدار از قبل می‌خواند»، با `sponsored` وقتی پول رد و بدل شده.

سایت جدید: کندی را انتظار داشته باش. سرعت جعلی همان شروع طرح است.

## چطور مطمئن شوی

| ابزار | قبول | رد |
| --- | --- | --- |
| GSC ← Links | هاست ارجاع‌دهنده را می‌شناسی | ترک ناگهانی PBN ناشناس |
| `curl -I` مقصد | `200`، ایندکس‌پذیر، self-canonical | `noindex`، 404، زنجیرهٔ ریدایرکت |
| جاگذاری | ارجاع بدنه، مقالهٔ مرتبط | فوتر / سایدبار سایت‌واید |
| تجاری در مقابل تحقیق | پول رد شد ← `rel` qualified | پست پولی، `follow` خام |
