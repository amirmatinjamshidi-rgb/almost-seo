## مفهوم

تاکتیک یعنی *چطور* بعد از داشتن چیزی ارزش ارجاع، درخواست citation می‌کنی. الگوی ماندگار: ادیتور یا وب‌مستر واقعی مشکل خواننده دارد، URL تو حلش می‌کند، لینک اختیاری و earned است.

الگویی که در ۲۰۲۶ هنوز به‌تنهایی scheme نیست:

- **Digital PR / روزنامه‌نگاری داده** — عدد اصلی، نظرسنجی، روش آزمایشگاه، دیتاست عمومی. داستان را پیچ کن، نه انکر را.
- **ارجاع منبع / داک** — داک رسمی، فهرست دانشگاه، صفحهٔ دولتی که از قبل لینک جمع می‌کند. درخواست به‌روزرسانی، نه «کازینو مرا اضافه کن.»
- **جایگزینی لینک شکسته** — معادل زنده وقتی hrefشان `404` است. هنوز editorial است؛ می‌توانند نه بگویند.
- **پیگیری mention بدون لینک** — اسمت را نوشتند؛ URL می‌خواهی. یک ایمیل، نه بلست.
- **داک پارتنر و اینتگریشن** — نرم‌افزاری که واقعاً وصل می‌شود، با URL داک قابل crawl.

الگویی که **سیاست اسپم** است یا چسبیده (جزئیات در طرح لینک): PBN، شبکهٔ گست‌پست پولی، اسپم کامنت/پروفایل/ویکی، قیف 301 دامنهٔ منقضی، مقالهٔ site-reputation-abuse روی هاست اجاره‌ای برای کلمه.

صف روزنامه‌نگار سبک HARO و فروشندهٔ «insert لینک» روی طیف‌اند. اگر پول URL را می‌خرد و مقاله وگرنه وجود نداشت، qualify کن (`sponsored`) یا ولش کن.

## چرا مهم است

فهرست تاکتیک بدون کف کیفیت می‌شود مسئلهٔ خرید: آژانس حجم می‌دهد، حقوقی scheme به ارث می‌برد. سه کانال بردار که برندت یک سال بتواند تکرار کند.

<CorrectExample title="درست">
روش اندازه‌گیری crawl-log قابل تکرار منتشر کردی. پیچ:

```txt
Subject: Crawl waste on faceted URLs — method + dataset

Hi [Editor], we released a method and CSV for measuring Googlebot
hits on filter URLs vs canonical guides. Happy to walk through
limitations. URL: https://www.example.com/research/crawl-log-study
```

اگر ارجاع دادند، href انتخاب خودشان است. در قرارداد انکر اجباری نیست.
</CorrectExample>

<IncorrectExample title="غلط" why="خرید فوتر سایت‌واید روی ۲۰۰ بلاگ link scheme است حتی اگر فاکتور بگوید «تبلیغات.»">

<footer>
  <a href="https://www.example.com/best-vpn">Best VPN 2026</a>

## پیاده‌سازی وردپرس

**Yoast SEO**

1. بعد از زنده شدن URL روابط‌عمومی، canonical یواست روی *صفحهٔ ارجاع‌شدهٔ تو* هنوز به خودش باشد.
2. پست نازک «برای outreach» نساز که یواست سبزش کند. دارایی باید خود محصول باشد.

**Rank Math**

1. schema Rank Math روی مطالعه (Article / Dataset اگر می‌خورد) به *فهم* کمک می‌کند. لینک خبرنگار را نمی‌سازد.
2. «auto-post به سوشال» را جایگزین پیچ به آدم نکن.

**AIOSEO**

1. همان: کارت preview سوشال برای دارایی‌ای که پیچ می‌کنی. `og:url` غلط کلیک خبرنگار را می‌سوزاند.
2. ۳۰ پست «contributor» روی بلاگ خودت انبوه نکن تا PR شبیه‌سازی شود.

**جا خالی واقعی:** outreach در ایمیل/CRM زندگی می‌کند، نه در Yoast. SEOPress / Rank Math / AIOSEO برنامهٔ digital PR اجرا نمی‌کنند. اگر upsell «بک‌لینک بگیر» داشتند، نادیده بگیر.

## پیاده‌سازی کد

دارایی را به‌صورت URL پایدار قابل اشتراک بفرست. اختیاری: بلوک citation تا خبرنگار href درست کپی کند.

```tsx
export function CiteThis({ url, title }: { url: string; title: string }) {
  const snippet = `<a href="${url}">${title}</a>`;
  return (
    <aside>
      <h2>Cite this study</h2>
      <pre>{snippet}</pre>
    </aside>
  );
}
```

App Router: `CiteThis` را روی صفحهٔ مطالعهٔ سرور-رندر بگذار. Pages Router: همان کامپوننت در صفحه. تنها کپی دیتاست را پشت مودال کلاینت با HTML اول خالی قایم نکن.

UTM روی URL پیچ‌شده: برای آنالیتیکس خوب است. canonical باید tracking را بکند تا گوگل `?utm_source=pitch` را ایندکس نکند.

## اشتباه‌های رایج و افسانه‌های منسوخ

- **DEPRECATED:** اسپم کامنت و پروفایل فروم به‌عنوان رژیم لینک «شروع‌کننده.»
- **DEPRECATED:** صفحهٔ لینک متقابل («دوستان ما») به‌عنوان استراتژی.
- **DEPRECATED:** اینفوگرافیک به‌عنوان آهنربای لینک تضمینی سبک ۲۰۱۲.
- خرید «درج لینک در پست قدیمی» در مقیاس بدون `sponsored`.
- پیچ انکر exact-match در جملهٔ اول هر ایمیل.
- زیردامنهٔ جدید per کمپین تا هر «property» به `/` لینک بدهد.

## نکته‌های سطح بالا / پروداکشن

ظرفیت: یک پژوهشگر + یک pitcher از فهرست ۴۰ بلاگی که نمی‌خوانی بهتر است. **لاگ جاگذاری** نگه دار (تاریخ، هاست، URL، پولی/غیرپولی، `rel`، URL هدف) در git یا شیت. برای تصمیم disavow و برای حقوقی لازم می‌شود.

بین‌المللی: ناشر فارسی به `/fa/` و ناشر انگلیسی به `/en/` ارجاع بدهد بهداشت hreflang است، نه «لینک تکراری.»

اگر فروش از قبل اسپانسرشیپ می‌خرد، کار SEO همان `rel` و URL فرود است — نه تظاهر که آن لینک‌ها editorialاند.

## چطور مطمئن شوی

| ابزار | قبول | رد |
| --- | --- | --- |
| لاگ جاگذاری در مقابل href زنده | URL هدف `200` | لینک به 404 / dump هوم‌پیج |
| ناشر | سرصفحهٔ واقعی، بایلاین واقعی | شبکهٔ بلاگ خالی WP |
| قرارداد | انکر اختیاری؛ پولی ← `sponsored` | «هفته‌ای ۱۰ پست dofollow» |
| هاست ارجاع‌دهندهٔ جدید GSC | اسمی که پیچ کردی یا انتظار داری | TLD تصادفی یک‌شبه |
