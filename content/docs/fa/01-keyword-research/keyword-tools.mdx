## مفهوم

**ابزار کلمه** تقاضا یا سختی را تخمین می‌زند. هیچ‌کدام API رتبهٔ گوگل نیستند.

استک حقیقت زمین:

- **Google Search Console** — کوئری‌هایی که از قبل به URL *تو* خورده: impression، کلیک، میانگین موقعیت. به چیزی که از قبل نشان می‌دهی سوگیری دارد. بهترین برای گسترش و cannibalization.
- **Google Keyword Planner** / Ads — تقاضای آگهی‌دهنده، ایدهٔ گروه‌شده، بازه. برای آگهی ساخته شده. حجم سطل‌بندی است، وعدهٔ اندازهٔ ارگانیک نیست.
- **Autocomplete / «People also ask» / related** — زبان زنده، بدون «نمرهٔ سختی.»
- **ابزار شخص ثالث** (Ahrefs، Semrush و بقیه) — مدل SERP crawlشده، تخمین clickstream، هم‌پوشانی URL رقیب. مفید، **گوگل نیست.** نمره اختصاصی است.

همچنین: لاگ سرچ سایت، تیکت پشتیبانی، تماس فروش — کوئری‌ای که ابزار هیچ‌وقت اختراع نکرد.

تخمین «KD ۱۲» را سند گوگل ندان. سختی یعنی «امروز صفحهٔ یک کیست،» که با نگاه به SERP دیده می‌شود.

## چرا مهم است

تیم از CSV حجم تقویم می‌فرستد و بعد می‌پرسد چرا SERP لوکال پک یا گرید شاپینگ است. ابزار بدون چک SERP همان انتخاب نیت غلط است.

## پیاده‌سازی وردپرس

**Yoast SEO**

1. Yoast شامل Keyword Planner نیست. title را از بریف بگذار؛ نگذار چراغ راهنمایی کوئری را بردارد.
2. یکپارچگی GSC در WP (Site Kit یا native) برای پایش است، نه ریختن همهٔ کوئری در پیش‌نویس.

**Rank Math**

1. Google Trends / «پیشنهاد کلمه» در Rank Math اگر هست تخمین اضافه است. باز SERP را ببین.
2. Instant Indexing انتخاب کلمهٔ بد را رتبه نمی‌دهد.

**AIOSEO**

1. SEO Analyzer / ایدهٔ کلمه در AIOSEO: همان caveat.
2. «فایل محتوا» ۵۰۰ عنوان شخص ثالث را خودکار به پیش‌نویس sync نکن.

**جا خالی واقعی:** Site Kit + Yoast/Rank Math/AIOSEO/SEOPress جایگزین بازبینی SERP نمی‌شوند. پیشنهاد داخل پلاگین Rank Math راحت و کم‌عمق‌تر از GSC + مغز تو است.

## پیاده‌سازی کد

ابزار بیرون سایت است. چیزی که پیاده می‌کنی **اختراع حجم داخل اپ** نیست. اختیاری: لاگ سرچ داخلی برای خوراک تحقیق (با احترام به حریم):

```ts
export async function POST(req: Request) {
  const { q } = await req.json();
  if (typeof q !== "string" || q.length > 200) {
    return Response.json({ ok: false }, { status: 400 });
  }
  await logSiteSearch(q); // aggregate, no PII in the string policy
  return Response.json({ ok: true });
}
```

Route Handler در App Router. Pages Router: مسیر API. توکن یا ایمیل لاگ نکن. لاگ را به‌عنوان مزرعهٔ ایندکس‌پذیر `/search?q=` افشا نکن (تلهٔ crawl ماژول ۰۳).

`sitemap.ts` برای URLهایی که انتخاب کردی می‌ماند، نه برای هر ردیف ابزار.

## اشتباه‌های رایج و افسانه‌های منسوخ

- **DEPRECATED:** حجم exact-match به‌عنوان تنها KPI تیم محتوا.
- **DEPRECATED:** سختی کلمه به‌عنوان متریک گوگل.
- **DEPRECATED:** ابزار LSI.
- پول دادن به ابزار و هیچ‌وقت باز نکردن GSC.
- فقط ابزار انگلیسی برای تقاضای فارسی (پوشش بدتر است؛ GSC + آدم می‌برد).
- حساب کردن «فهرست کلمه» ChatGPT به‌عنوان دادهٔ تقاضا. مدل زبان‌اند، clickstream نه.

## نکته‌های سطح بالا / پروداکشن

بودجه: GSC اجباری است. Ads Planner برای خیلی سایت‌ها کافی است. سوئیت شخص ثالث برای **URL رقیب** و گراف لینک می‌ارزد، نه حجم قشنگ‌تر.

فارسی: مخلوط ی/ک عربی و فارسی، محاوره در مقابل رسمی. ابزار این‌ها را جدا می‌کند؛ خوشه نباید.

هرگز جدول حجم اختراعی در این دانشنامه یا دک مشتری بدون ذکر ابزار و تاریخ به‌عنوان تخمین منتشر نکن.

## چطور مطمئن شوی

| ابزار | قبول | رد |
| --- | --- | --- |
| بریف | یادداشت SERP + GSC یا منبع شکاف | فقط ستون حجم |
| URL جدید | اول خوشه تصمیم گرفته شده | یک ردیف = یک پست |
| GSC بعد از انتشار | خانوادهٔ کوئری ظاهر می‌شود | فقط رأس stuffed، یا هیچ |
| سرچ سایت | `/search` با noindex، نه در sitemap | URL کوئری ایندکس‌شده |
