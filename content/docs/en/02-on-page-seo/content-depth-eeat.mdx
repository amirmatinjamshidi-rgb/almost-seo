## Concept

**Depth** means the document finishes the job the SERP assigned (Module 01 intent). A calculator query needs a working calculator. A policy query needs accurate current rules. A product query needs specs and stock truth. Word count is a byproduct, not a target.

**On-page E-E-A-T** (Experience, Expertise, Authoritativeness, Trust — rater concept, Module 04 off-page) here is *visible*: byline of a real person, date, method, sources, “we measured / we shipped,” contact, HTTPS. JSON-LD does not replace a bio. Fake “ medically reviewed by” is worse than none (Module 04 / 09 YMYL).

Thin content and **doorway pages** (scaled near-duplicates for queries) are spam policies. Refreshing a date stamp without adding substance is not depth.

## Why it matters

Shallow pages bounce and fail raters. Inflated pages that repeat the SERP’s first result with extra adjectives also fail. Depth is *coverage of the job*, not length.

## WordPress implementation

**Yoast SEO**

1. Yoast readability / word-count bars are not Google. Ignore “too short” on a correct 400-word definition page.
2. Author archives: real bios or `noindex` empty authors.

**Rank Math**

1. Rank Math content score will nag for more headings/keywords. Do not pad to green.
2. Schema Person: only real users.

**AIOSEO**

1. AIOSEO TruSEO same trap.
2. “E-E-A-T” modules that add empty award lists: fill or disable.

**Feature gap:** All four plugins score tokens. None can tell a domain expert from a spinner. SEOPress readability is the same class.

## Code implementation

```tsx
export default async function Page() {
  const doc = await getDoc("robots-txt");
  return (
    <article>
      <h1>{doc.title}</h1>
      <p>
        Last reviewed {doc.lastReviewed} · {doc.authors.join(", ")}
      </p>
      {doc.body}
    </article>
  );
}
```

App Router: body from MDX/CMS on the server. Pages Router: `getStaticProps`. Do not hide the only unique paragraphs behind a “read more” that is not in the HTML.

Author pages as real routes if you claim people (Module 04).

## Common mistakes and outdated myths

- **DEPRECATED:** Minimum 300 / 500 / 2,000 words to rank.
- **DEPRECATED:** “Skyscraper” as copy the top result and add 500 words.
- Date-only refreshes (`Updated 2026`) with no diff.
- Doorway city pages as “depth at scale.”
- E-E-A-T as a plugin checkbox.

## Senior / production notes

Briefs should list **questions the URL must answer**, sourced from SERP + GSC + SMEs, not a word count. For YMYL, named reviewer and date are operational, not decorative.

Prune or merge thin URLs (Module 06) rather than padding them.

This encyclopedia’s `last_reviewed` frontmatter is the honesty mechanism — keep it real when you edit.
